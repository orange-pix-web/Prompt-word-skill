# Prompt Word Skill · 生图工作台

一个零依赖、本地运行的浏览器管理器，用于管理`D:\ZC\主图2`中的产品、分类、标签、主图模板、参考图和生图提示词。

## 已实现

- 产品缩略图、搜索、分类和标签管理
- 添加产品和新分类
- 产品跨分类移动，产品图与历史提示词一起移动
- 主图模板新增、编辑、启停、分组筛选和线框预览；支持新建、重命名、删除分组及批量移动模板
- 模板分组与模板归属独立保存到`.prompt-ui/template-groups.json`，不改变原有Markdown模板格式
- 1024×1024可视化模板画布：绘制、拖动、缩放标题、多个产品、任意数量卖点、净含量和底栏
- 文字字号默认取所画矩形框高度的80%，底板形状与最终提示词保持一致
- 新模板可直接通过可视化布局方式添加，坐标独立保存到`.prompt-ui/template-layouts.json`
- 模板画布可按分类和示例产品预览真实营销文案
- 左侧“营销文案”按产品名称列表管理文案，也可切换到产品分类或全局通用范围
- 营销文案支持按换行批量添加；每条文案可绑定多个位置属性，同一张主图内只使用一次
- 产品专属营销词优先于分类通用词和全局通用词；模板只决定卖点数量与顶部、侧栏、底部位置
- 生成提示词时可选择文案来源，也可切换为只使用手动勾选的部分文案
- 删除营销词或模板元素前会二次确认，删除后可立即撤销；保存后进入回收站并保留30天
- 保存模板和产品营销词前自动备份到`.prompt-ui/backups`，回收站数据保存在`.prompt-ui/recycle-bin.json`
- 模板编辑器支持同时预览多个产品，并让每个产品框绑定指定产品槽位
- `产品图/产品模板`作为独立透明素材库，添加产品时可选包装与商标生成产品草图
- 通用图层：可以重复添加任意数量的产品、卖点、标题、自定义文字、动物区域、背景区域和装饰形状
- 图层形状支持无底板、直角矩形、圆角矩形、圆形、椭圆、胶囊和平行四边形
- 支持“多个产品分别生成”和“多个产品放在同一张主图”两种生成模式
- 勾选任意产品和模板生成新版提示词
- 参考图导入并生成可编辑模板草稿
- 支持不上传参考图、单独粘贴或选择JSON文件导入模板图层
- 可选OpenAI视觉模型分析入口
- 所有文件只在本机项目目录中读写

## 启动

本机需要Node.js 22或更高版本。

```powershell
node server.mjs
```

然后打开：

```text
http://127.0.0.1:4178
```

也可以直接双击项目根目录中的`打开生图工作台.cmd`。脚本会自动启动本地服务并打开浏览器，不需要手动输入网址。

如果电脑未安装Node.js 22或更高版本，启动器会弹窗提示，并可通过“是”按钮打开Node.js官方下载页面。安装完成后重新双击启动按钮即可。

## 移动项目

建议移动整个`主图2`文件夹，不要只移动`Prompt-word-skill`。工作台默认把自身上一级目录识别为数据目录，因此整包移动后，产品图、模板、营销文案和历史提示词仍会自动对应，不需要修改绝对路径。

如果只移动UI程序，需要在启动前通过`PROMPT_DATA_ROOT`指定实际数据目录。

在Codex提供的内置Node环境中可以使用：

```powershell
& "C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" "D:\ZC\主图2\Prompt-word-skill\server.mjs"
```

默认数据目录是UI仓库的上一级，也就是`D:\ZC\主图2`。也可以临时指定：

```powershell
$env:PROMPT_DATA_ROOT="D:\其他主图项目"
node server.mjs
```

## 可选AI参考图分析

“参考图分析”提供两条互不依赖的流程：

- 上传参考图：不配置API时保存图片并生成基础草稿；配置视觉模型后自动识别产品、标题、卖点、净含量、底栏、动物和背景区域。
- 独立导入JSON：无需上传图片或配置API，可粘贴JSON或选择`.json`文件，校验通过后直接进入可视化模板编辑器。
- JSON导入区内置可复制的AI分析提示词和标准示例，“填入示例”使用同一份格式。

JSON中的`elements`可使用数组，也可使用工作台原生的`visualLayout.elements`对象。坐标`x`、`y`、`w`、`h`统一使用0–100百分比。
导入器兼容AI常见的`background`、`animal`、`text`、`point`、`badge`等类型别名，并自动转换为工作台图层。

要启用视觉模型自动分析，请在启动前设置：

```powershell
$env:OPENAI_API_KEY="你的API密钥"
$env:OPENAI_VISION_MODEL="支持图像输入的模型名称"
node server.mjs
```

API密钥只从本机环境变量读取，不会保存到网页或仓库。

## 数据安全

- 服务只监听`127.0.0.1`，局域网和互联网无法直接访问。
- 所有路径经过项目根目录边界检查。
- 提示词自动使用新版本号，不覆盖历史文件。
- 产品转移前检查目标同名文件，存在冲突时停止。
